## 2. 시연 (현준 👤)

배포 주소에서 **저장 → 재로그인 → 재실행 → 전처리 확인 카드**를 직접 구동한다. 세 PR이 합쳐지고 운영 배포·마이그레이션 적용이 끝난 뒤, 한 단계씩 안내받아 진행한다.

| 순서 | 할 일 | 확인 |
|---|---|---|
| 1 | 배포 주소에서 로그인 → 질문 → 결과를 프로젝트로 **저장** | _(병합 후 채움)_ |
| 2 | 로그아웃 → 다시 로그인 → "내 분석" 목록에서 방금 저장한 분석 열기 | _(병합 후 채움)_ |
| 3 | **재실행** → 같은 수치인지, 어느 데이터 버전 기준인지 확인 | _(병합 후 채움)_ |
| 4 | 결측·중복이 있는 경우의 **전처리 확인 카드** → 처리 방법 선택 → 전후 행 수·합계 | _(병합 후 채움)_ |
