### 2.1 확인하면서 빠져 있던 것과 고친 것
| 종류 | 빠져 있던 것 | 고친 것 |
|---|---|---|
| 막대·선 | **X축 이름이 없었다** (계산 엔진 `buildCharts`는 `xAxisLabel`을 보내지 않음, 가짜 결과에만 있었음) | 차트 아래에 X축 이름 표시. 서버가 안 주면 x 값 모양으로 "분기"·"연도"·"구분" (`xAxisTitle`) |
| 막대·선 | `yAxisLabel`이 없으면 단위가 사라졌다 | 계열 단위로 채움 ("%"·"배"·"원", `yAxisTitle`), "(조 원)"처럼 괄호로 단위임을 표시 |
| 선 | 2계열 이상이면 선 모양만 달랐고 **표시점은 모두 같은 동그라미** | 계열마다 동그라미·네모·세모·마름모 |
| 막대 | 둘째 계열만 빗금이고 **셋째부터 다시 색만**, 증감 막대(상승 빨강·하락 파랑)는 무늬가 사라짐 | 계열마다 채움·빗금·점·격자, 증감 막대도 계열 무늬 유지 |
| 막대·선 | 범례가 Recharts 기본이라 **셋째 계열 무늬·선 표시점 모양이 견본에 없었고**, 용어 설명 버튼도 넣을 수 없었다 | 차트와 같은 선 모양·표시점·무늬 견본의 범례를 직접 그림 (그림 밖이라 용어 버튼도 누를 수 있음) |
| 막대·선 | "표로 보기"는 `aria-pressed`만 있고 **무엇을 여는지 알 수 없었다** | `aria-expanded` + `aria-controls`(표 칸 ID) |
| 모두 | 출처가 비면 아무것도 안 보였다 | 비면 "출처: DART", "출처:"가 없으면 붙임 (`sourceText`) |
| 모두 | 재무 용어 설명이 없었다 (F-Z5) | `src/components/glossary/` 용어 사전 + `Term` — 차트 제목·범례·표 머리글·지표 카드·분석 기준 바(연결/별도·주의 표시)·사용된 데이터 열 이름 |

### 2.2 재무 용어 설명 (PRD F-Z5)
- 사전: `src/components/glossary/terms.ts` — 계산 엔진 지표(`METRIC_LABEL`) 14개 전부 + TTM·지배주주순이익·자기자본·연결·별도. 한 문장씩.
- 동작: 마우스 올리기, Tab으로 옮겨 오기, 누르기(휴대폰 탭) 모두 설명이 뜬다. 누르면 고정, 다시 누르거나 바깥을 누르거나 Esc로 닫힌다. 설명은 `aria-describedby`로 이어져 화면 낭독기가 함께 읽는다. 화면 가장자리·가로 스크롤 표 안에서도 잘리지 않는다(375px 확인).
- 분석 글(`ExplanationPanel.tsx`)에는 아직 붙이지 않았다 (Phase 3 동안 다른 작업이 그 파일을 고치는 중 — 통합 때 판단).
