## 1. 한 줄 요약

금융감독원 전자공시 **OpenDART API**에서 받은 공시·재무 데이터를 가공하여, 한 기업의 **분기·연간 실적**, **주요 경영 이슈**, **동종 섹터·경쟁사 비교**를 **한 페이지에서** 확인할 수 있는 회원제 대시보드 웹 서비스.

---

## 2. 배경 및 문제 정의

### 2.1 배경
- 기업의 실적과 경영사항은 DART(전자공시시스템)에 모두 공개되어 있지만, 원문은 **보고서 단위의 긴 문서**로 흩어져 있다.
- 투자 판단에 필요한 정보는 대부분 다음 세 가지 질문으로 모인다.
  1. 이 회사는 **돈을 잘 벌고 있는가?** (실적 추이)
  2. 최근 **무슨 일이 있었는가?** (주요 경영사항·공시 이슈)
  3. **비슷한 회사들과 비교하면** 어떤가? (섹터·경쟁사 비교)

### 2.2 문제
| # | 사용자가 겪는 문제 | 결과 |
|---|---|---|
| P1 | 기업별로 사업보고서·분기보고서를 하나씩 열어 숫자를 찾아야 한다 | 시간이 많이 든다 |
| P2 | 3분기 보고서는 누적 실적이라 분기별 실적(특히 4분기)을 직접 계산해야 한다 | 계산 실수, 추이 파악 어려움 |
| P3 | 유상증자·합병·최대주주 변경 같은 중요 공시가 일반 공시 사이에 묻힌다 | 중요 이슈를 놓친다 |
| P4 | 경쟁사 비교를 하려면 여러 회사의 데이터를 따로 모아 엑셀로 정리해야 한다 | 비교 분석을 포기하게 된다 |
| P5 | 숫자는 있지만 "그래서 이게 좋은 건지 나쁜 건지" 맥락이 없다 | 해석이 어렵다 |
| P6 | 사이트마다 PER·PBR 계산 기준이 달라 숫자가 서로 다르다 | 어떤 숫자를 믿어야 할지 모른다 |

## 3. 목표 / 비목표

### 3.1 핵심 목표 (Goals)
| ID | 목표 | 설명 |
|---|---|---|
| G1 | **실적 한눈에 보기** | 분기·연간 매출, 영업이익, 순이익과 증감률을 차트로 확인 |
| G2 | **경영 이슈 파악** | 주요사항보고서·지분 변동 등 중요 공시를 중요도 순으로 정리해 제공 |
| G3 | **비교 분석** | 같은 섹터 및 사용자가 고른 경쟁사와 핵심 지표를 **동일한 계산 기준**으로 나란히 비교 |
| G4 | **맥락 제공** | 수치 변화와 공시 내용을 AI(LLM)가 짧은 문장으로 요약 |
| G5 | **한 페이지 완결** | 위 G1~G4를 기업 상세 페이지 하나에서 스크롤만으로 확인 가능 |
| G6 | **공정한 사용** | 회원별 하루 사용 한도로 소수의 과다 사용이 전체 서비스를 멈추지 않도록 보호 |

### 3.2 비목표 (Non-Goals) — 이번 버전에서 하지 않는 것
- 매수·매도 추천, 목표주가 제시 등 **투자 자문 행위**
- 실시간 주가 시세, 호가, 차트 트레이딩 기능 (주가는 **전 거래일 종가** 기준만 사용)
- 회원 포트폴리오 관리·수익률 계산
- 아이디·비밀번호 방식의 자체 회원가입 (소셜 로그인만 제공, §6.8)
- 모바일 전용 앱 (반응형 웹으로만 대응)
- 해외 기업 데이터

## 5. 핵심 사용자 시나리오

0. **첫 방문 (비로그인)**
   사이트에 들어오면 **SK하이닉스** 대시보드가 기본으로 보인다. 스크롤과 차트 수치 확인은 가능하지만, 검색·기간 변경·경쟁사 추가 등을 누르면 "로그인 후 이용할 수 있습니다" 안내와 함께 로그인 페이지로 이동한다.
1. **로그인**
   카카오 또는 구글 계정으로 버튼 한 번에 로그인한다. 처음이면 이용약관·개인정보 처리방침 동의 후 가입이 완료된다.
2. **기업 검색 → 상세 진입**
   검색창에 "삼성전자" 또는 종목코드 "005930"을 입력 → 자동완성 목록에서 선택 → 기업 대시보드로 이동. 화면 한쪽에 "오늘 남은 조회 17/20회"가 보인다.
3. **실적 확인**
   상단 카드에서 최근 분기 핵심 숫자를 확인 → 아래 차트에서 **최근 4개 분기** 추이를 본다. 더 긴 기간이 필요하면 기간 설정에서 "최근 3년", "2015년부터" 등으로 넓힌다.
4. **이슈 확인**
   "주요 경영사항" 영역에서 최근 중요 공시(예: 유상증자 결정, 최대주주 변경)와 AI 요약을 확인 → 항목을 누르면 DART 원문 링크로 이동한다.
5. **비교 분석**
   "비교 분석" 영역에서 같은 섹터 기업들과 영업이익률·PER·PBR 등을 비교 → 경쟁사를 직접 추가·삭제한다. 은행·보험처럼 재무제표 구조가 다른 기업도 공통 지표로 바꿔 비교된다.
6. **다시 보기**
   "내 조회 이력"에서 최근에 본 기업을 다시 연다. 이미 저장된 데이터로 빠르게 뜬다.

#### 6.5.1 섹터 분류 (Q3 결정)
- 공식 업종코드가 아니라 **개인투자자들이 흔히 묶는 범주**(예: 반도체, 2차전지, 자동차, 조선, 방산, 바이오, 인터넷/플랫폼, 게임, 엔터, 은행, 증권, 보험 등)로 표기한다.
- 분류는 우리 쪽 **섹터 매핑표**로 관리한다. 전체 목록과 분류 규칙은 TECH_SPEC에서 정의한다.

#### 6.5.2 PER·PBR 등 주가 기반 지표 (Q1 결정)
- 외부 사이트 값을 가져오지 않고 **우리가 직접 계산**한다.
- 모든 기업에 **항상 같은 계산 기준**을 적용하고, 화면에 계산 기준을 한 줄로 표시한다 (예: "PER = 전 거래일 종가 기준 시가총액 ÷ 최근 4개 분기 지배주주 순이익").
- 계산식은 TECH_SPEC에 버전과 함께 고정하고, 바꿀 때는 버전을 올려 기록한다.

## 7. 데이터 소스

| 데이터 | 출처 | 비고 |

### 7.1 OpenDART 사용 범위
| 사용 목적 | API 분류 | 대표 API |
|---|---|---|
| 기업 검색 / 기본 정보 | 공시정보 | 고유번호, 기업개황 |
| 공시 목록·원문 | 공시정보 | 공시검색, 공시서류원본파일 |
| 실적 수치 | 정기보고서 재무정보 | 단일회사 전체 재무제표, 다중회사 주요계정 |
| 배당·최대주주 등 | 정기보고서 주요정보 | 배당에 관한 사항, 최대주주 현황 등 |
| 지분 변동 | 지분공시 종합정보 | 대량보유 상황보고, 임원·주요주주 소유보고 |
| 주요 경영사항 | 주요사항보고서 주요정보 | 유상증자·합병·자기주식 취득 결정 등 |

### 7.2 확인된 데이터 제약
- OpenDART 재무정보는 **2015년 이후**만 제공된다 → 조회 기간 최대 범위의 근거.
- 보고서 구분: `11013`(1분기), `11012`(반기), `11014`(3분기), `11011`(사업보고서=연간). **4분기 단독 보고서는 없다.**
- 다중회사 조회는 **한 번에 최대 100개사**.
- OpenDART 인증키당 **일일 요청 한도**가 있다(초과 시 오류코드 `020`, 약 2만 건 수준). → 저장·재사용 구조와 회원별 한도가 필요하다.
- 주가 데이터는 OpenDART에 없어 공공데이터포털 주가 API를 쓴다. 이 API는 **다음 영업일 오후 1시 이후** 갱신되고, 개발 계정 기준 **하루 10,000건** 한도가 있다.
- 주가 API의 이용 조건은 **"출처표시, 상업적 이용금지, 변경금지"** 이다. → 본 프로젝트는 비상업 학습용으로 사용하며, 상업화 시 한국거래소 데이터 구매가 필요하다 (§11 리스크).

## 8. 비기능 요구사항

| 구분 | 요구사항 |
|---|---|

| 정확성 | 표시 수치는 DART 원본과 일치해야 하며, 계산값(4분기, 증감률, 비율, PER·PBR)은 계산식을 버전과 함께 문서화 |
| 계산 일관성 | 같은 지표는 모든 기업·모든 화면에서 같은 계산식을 쓴다 |
| 보안 | 모든 API 인증키는 서버에만 보관하고 브라우저·공개 저장소에 노출하지 않는다. 회원은 자기 조회 이력만 볼 수 있다 |
| 개인정보 | 개인정보는 최소 수집, 탈퇴 시 삭제, 처리방침 공개 |
| 가용성 | 외부 API 장애·한도 초과 시에도 저장된 데이터로 화면을 보여주고 "기준 시점"을 표시 |
| 비용 | AI 요약은 저장·재사용하여 같은 내용을 두 번 만들지 않는다. 하루 AI 사용량 상한을 둔다 |
| 접근성 | 차트는 색상만으로 구분하지 않고 수치·라벨을 함께 제공 |

## 9. 법적·윤리적 고려사항

- 본 서비스는 **투자 자문이 아니다.** 모든 페이지에 다음 취지의 고지문을 표시한다.
  > 본 서비스는 금융감독원 전자공시(DART) 자료 등을 가공한 정보 제공 목적의 서비스이며, 투자 권유나 자문이 아닙니다. AI 요약은 오류가 있을 수 있으며, 투자 판단과 그 결과의 책임은 이용자 본인에게 있습니다.
- AI 요약과 자동 문장에 "매수", "매도", "추천", "목표주가" 같은 권유 표현을 쓰지 않는다.
- OpenDART·공공데이터포털 이용 조건(출처 표시 등)을 준수한다.
- 개인정보 보호법에 따라 개인정보 처리방침을 공개하고 동의를 받는다.
