## 1. 한 줄 요약

금융감독원 전자공시 **OpenDART API**에서 받은 공시·재무 데이터를 가공하여, 한 기업의 **분기·연간 실적**, **주요 경영 이슈**, **동종 업종·경쟁사 비교**를 **한 페이지에서** 확인할 수 있는 대시보드 웹 서비스.

---

## 2. 배경 및 문제 정의

### 2.1 배경
- 기업의 실적과 경영사항은 DART(전자공시시스템)에 모두 공개되어 있지만, 원문은 **보고서 단위의 긴 문서**로 흩어져 있다.
- 투자 판단에 필요한 정보는 대부분 다음 세 가지 질문으로 모인다.
  1. 이 회사는 **돈을 잘 벌고 있는가?** (실적 추이)
  2. 최근 **무슨 일이 있었는가?** (주요 경영사항·공시 이슈)
  3. **비슷한 회사들과 비교하면** 어떤가? (섹터·경쟁사 비교)

### 2.2 문제
| # | 사용자가 겪는 문제 | 결과 |
|---|---|---|
| P1 | 기업별로 사업보고서·분기보고서를 하나씩 열어 숫자를 찾아야 한다 | 시간이 많이 든다 |
| P2 | 3분기 보고서는 누적 실적이라 분기별 실적(특히 4분기)을 직접 계산해야 한다 | 계산 실수, 추이 파악 어려움 |
| P3 | 유상증자·합병·최대주주 변경 같은 중요 공시가 일반 공시 사이에 묻힌다 | 중요 이슈를 놓친다 |
| P4 | 경쟁사 비교를 하려면 여러 회사의 데이터를 따로 모아 엑셀로 정리해야 한다 | 비교 분석을 포기하게 된다 |
| P5 | 숫자는 있지만 "그래서 이게 좋은 건지 나쁜 건지" 맥락이 없다 | 해석이 어렵다 |

## 3. 목표 / 비목표

### 3.1 핵심 목표 (Goals)
| ID | 목표 | 설명 |
|---|---|---|
| G1 | **실적 한눈에 보기** | 분기·연간 매출, 영업이익, 순이익과 증감률을 차트로 확인 |
| G2 | **경영 이슈 파악** | 최근 주요사항보고서·지분 변동 등 중요 공시를 중요도 순으로 정리해 제공 |
| G3 | **비교 분석** | 같은 업종 및 사용자가 고른 경쟁사와 핵심 지표를 나란히 비교 |
| G4 | **맥락 제공** | 수치 변화에 대해 "무엇이 달라졌는지"를 짧은 문장으로 요약 |
| G5 | **한 페이지 완결** | 위 G1~G4를 기업 상세 페이지 하나에서 스크롤만으로 확인 가능 |

### 3.2 비목표 (Non-Goals) — 이번 버전에서 하지 않는 것
- 매수·매도 추천, 목표주가 제시 등 **투자 자문 행위**
- 실시간 주가 시세, 호가, 차트 트레이딩 기능
- 회원 포트폴리오 관리·수익률 계산
- 모바일 전용 앱 (반응형 웹으로만 대응)
- 해외 기업 데이터

## 4. 대상 사용자

| 페르소나 | 특징 | 핵심 니즈 |
|---|---|---|
| **개인 투자자 (주 타깃)** | 주식 투자 1~5년 차, 공시 원문 읽기는 부담스러움 | 빠르게 "이 회사 요즘 어때?"를 파악 |

## 5. 핵심 사용자 시나리오

1. **기업 검색 → 상세 진입**
   사용자가 검색창에 "삼성전자" 또는 종목코드 "005930"을 입력 → 자동완성 목록에서 선택 → 기업 대시보드 페이지로 이동.
2. **실적 확인**
   페이지 상단에서 최근 분기 핵심 숫자(매출·영업이익·순이익과 전년 동기 대비 증감률)를 카드로 확인 → 아래 차트에서 최근 몇 년간 분기/연간 추이를 전환하며 본다.
3. **이슈 확인**
   "주요 경영사항" 영역에서 최근 중요 공시(예: 유상증자 결정, 최대주주 변경)를 확인 → 항목을 누르면 요약과 DART 원문 링크가 보인다.
4. **비교 분석**
   "비교 분석" 영역에서 같은 업종 기업들과 영업이익률·부채비율 등을 비교 → 경쟁사를 직접 추가·삭제해 비교 대상을 바꾼다.

## 7. 데이터 소스

**OpenDART** (https://opendart.fss.or.kr) — 금융감독원 전자공시시스템의 공개 API. 누구나 인증키를 발급받아 사용할 수 있다.

| 사용 목적 | OpenDART API 분류 | 대표 API |
|---|---|---|
| 기업 검색 / 기본 정보 | 공시정보 | 고유번호, 기업개황 |
| 공시 목록 | 공시정보 | 공시검색 |
| 실적 수치 | 정기보고서 재무정보 | 단일회사 주요계정, 다중회사 주요계정, 단일회사 전체 재무제표 |
| 재무 지표 | 정기보고서 재무정보 | 단일·다중회사 주요 재무지표 |
| 배당·최대주주 등 | 정기보고서 주요정보 | 배당에 관한 사항, 최대주주 현황 등 |
| 지분 변동 | 지분공시 종합정보 | 대량보유 상황보고, 임원·주요주주 소유보고 |
| 주요 경영사항 | 주요사항보고서 주요정보 | 유상증자·합병·자기주식 취득 결정 등 |

### 7.1 확인된 데이터 제약
- 재무정보는 **2015년 이후**만 제공된다.
- 보고서 구분: `11013`(1분기), `11012`(반기), `11014`(3분기), `11011`(사업보고서=연간). **4분기 단독 보고서는 없다.**
- 다중회사 조회는 **한 번에 최대 100개사**.
- 인증키당 **일일 요청 한도**가 있다(한도 초과 시 오류코드 `020`). → 데이터를 미리 받아 저장(캐시)해두는 구조가 필요하다.
- **주가 데이터는 OpenDART에 없다.** 따라서 PER·PBR·시가총액 같은 주가 기반 지표는 이번 범위에서 제외하거나 별도 데이터 소스가 필요하다 (§11 참조).

## 8. 비기능 요구사항

| 구분 | 요구사항 |
|---|---|
| 성능 | 기업 페이지 첫 화면 표시 3초 이내 (캐시된 기업 기준) |
| 데이터 최신성 | 신규 정기보고서·주요 공시는 공시 후 24시간 이내 반영 |
| 정확성 | 표시 수치는 DART 원본과 일치해야 하며, 계산값(4분기, 증감률, 비율)은 계산식을 문서화 |
| 보안 | OpenDART 인증키는 서버에만 보관하고 브라우저·공개 저장소에 노출하지 않는다 |
| 가용성 | 외부 API 장애 시에도 마지막으로 저장한 데이터로 화면을 보여주고 "기준 시점"을 표시 |
| 접근성 | 차트는 색상만으로 구분하지 않고 수치·라벨을 함께 제공 |

## 9. 법적·윤리적 고려사항

- 본 서비스는 **투자 자문이 아니다.** 모든 페이지에 다음 취지의 고지문을 표시한다.
  > 본 서비스는 금융감독원 전자공시(DART) 자료를 가공한 정보 제공 목적의 서비스이며, 투자 권유나 자문이 아닙니다. 투자 판단과 그 결과의 책임은 이용자 본인에게 있습니다.
- 자동 생성 요약 문장에 "매수", "매도", "추천" 같은 권유 표현을 쓰지 않는다.
- OpenDART 이용약관(출처 표시 등)을 준수한다.
